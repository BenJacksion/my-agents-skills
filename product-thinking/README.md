# 产品思维 Agents & Skills

将互联网一手来源中的产品思维方法提炼为可路由、可协作、可验证的 Agents 与 Skills，支持从用户问题发现、结果定义、假设验证到策略取舍和持续迭代的产品工作流。

## 内容

- `research.md`：产品思维一手来源研究、综合结论和来源清单。
- `skills/`：产品思维总入口、产品发现、结果与指标、假设测试、策略与优先级 Skills。
- `agents/`：产品思维负责人 Agent。
- `capability-catalog.md`：能力目录、来源映射、路由规则和质量门槛。
- `agent-contracts.md`：Agent 输入、输出、职责边界、交接条件和失败回退规则。

## 能力链路

默认编排顺序为：

```text
产品发现 -> 结果与指标 -> 假设测试 -> 策略与优先级 -> 持续迭代
```

根据任务边界可以从中间节点开始。例如，已有明确方案可直接做假设测试；只需要排路线图时可直接进入策略与优先级。

## 设计原则

- 先理解用户问题，再讨论功能方案。
- 用用户和业务结果判断价值，而不是只看产出数量。
- 把产品决策拆成可验证假设，优先验证高风险、低证据判断。
- 优先级是有限资源下的取舍，评分工具不替代策略和团队判断。
- 快速迭代的目标是缩短可靠学习周期，不是降低质量门槛。
- 所有结论都区分事实、假设、证据、判断和未决问题。
