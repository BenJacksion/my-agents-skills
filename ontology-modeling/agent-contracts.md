# 本体建模调用与交接契约

本文件约束调用 Skill 的 Agent；不新建专门的 Agent，也不重复保存建模方法。

## 输入

- 目标：待回答的能力问题、业务决策或需要执行的行动。
- 范围：领域边界、用户、上下文、已知词汇与不处理的内容。
- 证据：业务文档、现有模型、数据样本、来源与可信度。
- 环境：知识工程、运营或联合模式；目标语言、平台、版本和工具可未知。
- 约束：数据所有权、权限、时间语义、更新方式和外部系统责任。

缺失信息标记为未知；会改变模型方向的信息应集中澄清，示例不得升级为真实业务事实。

## 输出

- 事实、假设、证据、决策、未决问题分别记录。
- 问题与行动清单，以及到模型元素和验证用例的追溯。
- 概念/对象、实例、身份、属性、关系与规则归属。
- 数据源到模型的映射、更新责任与冲突处理。
- 所选模式的模型产物；语言或平台配置仅在任务需要时交付。
- 验证报告：输入、预期、实际、工具/版本、通过或失败；未运行则注明原因。
- 风险、维护责任、版本变更影响和下一步验证行动。

## 交接条件

- 知识工程：问题可查询或推理验证，公理与数据约束分离，身份和词汇复用决策明确。
- 运营：行动的对象修改、准入条件、授权、外部副作用和失败处理都有责任归属。
- 联合：共用业务词汇、实例标识映射和不等价项有记录；两侧分别通过各自质量门。

交给应用或数据架构时保留未知项和验证状态。设计完成不表示生产部署完成；不得把计划验证升级为已验证。
